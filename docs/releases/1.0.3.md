# StageOS 1.0.3 — ваши театры, ваши команды

StageOS теперь открывается с выбора театра и небольшого окна входа. Несколько театров работают на одном компьютере с отдельными базами, пользователями и расписаниями. Прежняя рабочая база сохраняется; для неё настраивается вход администратора.

В правом верхнем углу появились личный аккаунт, выход и переключение театра. Администратор управляет пользователями, ролями, отключением аккаунтов и сбросом паролей. Планировщики редактируют производственные данные, наблюдатели работают в режиме просмотра. Проверка прав выполняется сервером. Согласование, импорт базы и принудительное назначение доступны администраторам.

Пароли сохраняются в виде хешей; после выхода или перезапуска сервера снова требуется вход. Нельзя отключить последнего администратора. Данные принимающих площадок и сотрудников вашего театра не включены в публичный релиз. Персональные начальные аккаунты устанавливаются отдельной локальной настройкой; общего публичного пароля нет.

Перед обновлением закройте StageOS и сохраните резервную копию каталога данных. Распакуйте архив полностью и запустите StageOS/Windows-Portable/StageOS.exe. Подробнее: docs/ACCOUNTS_RU.md. Публикация разрешена только после серверных, UI- и Windows-проверок. Фактические результаты прилагаются. Windows 10/11 вручную не проверялись, приложение не подписано. Авторизация не шифрует локальные файлы базы.

## English

StageOS opens with theatre selection followed by a compact sign-in form. Each theatre has its own database, accounts and schedule. Existing local theatre data is preserved. Administrators manage users, roles, disabled accounts and password resets; planners edit production data and viewers have read-only access. Server permissions protect approvals, database imports and conflict overrides.

The personal account menu provides sign-out, password changes and theatre switching. Passwords are hashed, the last administrator is protected, and sessions end on sign-out or server restart. There are no public default credentials. Local database files are not encrypted. Actual test/build receipts are included; manual Windows 10/11 acceptance has not been performed.
