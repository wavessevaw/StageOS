# StageOS 1.0.2 — понятные сведения после импорта

Импортированная база теперь отображается как рабочие карточки: массивы и вложенные объекты не превращаются в `[object Object]`. Сведения об участии, должности, даты и ссылки собраны в отдельном разделе «Сведения из источников» с русскими и английскими подписями. История участия и постановочная команда раскрываются по нажатию.

В постановках показаны допущенные исполнители, даже если первый и второй состав ещё не определены. Импортированный неполный технический паспорт помечается как требующий заполнения; вычисленное время шаблона не выдаётся за фактическое время подготовки.

Обновление не требует повторного импорта и не меняет содержимое вашей базы. Перед обновлением экспортируйте резервную копию, закройте StageOS и распакуйте StageOS-Release-1.0.2.zip полностью. Запустите StageOS/Windows-Portable/StageOS.exe.

Публикация выполняется только после автоматических проверок Python, браузерного интерфейса и сборки/запуска окна Windows. Точные результаты прилагаются к релизу. Ручная приёмка Windows 10/11 не выполнена. Приложение не подписано, для окна требуется WebView2 Runtime. База театра в публичный релиз не включена.

## English

Imported records now display structured fields instead of `[object Object]`. Source information, production participation and credits have readable Russian/English labels and working source links. Eligible performers remain visible when casts have not yet been assigned. Incomplete imported technical passports are clearly marked; derived template preparation is not presented as actual preparation time.

No re-import is required. Existing database content is preserved. Back up the database, close StageOS, extract the complete archive and run the included executable. Exact automated test and Windows build results are included in the release; manual Windows 10/11 acceptance has not been performed.
