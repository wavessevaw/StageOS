# StageOS 1.0.5 — ваш спектакль, ваш производственный план

Планируйте подготовку под реальную работу театра: меняйте цепочку, распределяйте роли на конкретную дату и держите общий сервер под наблюдением.

## Что нового

- **Гибкая цепочка события.** Добавление и удаление этапов прямо в предварительном плане. Время, длительность и зависимости пересчитываются до сохранения. Пользовательские этапы появляются в календаре и производственной шкале.
- **Индивидуальный состав.** Выбор исполнителя каждой роли на отдельный спектакль. Можно смешивать первый и второй составы, сохраняя постоянный паспорт постановки.
- **Опыт театра помогает планировать.** Подсказки по повторяющимся подтверждённым назначениям, повторная проверка ресурсов и открытие предложения для подтверждения.
- **Небольшая локальная модель.** Загрузка через Ollama с прогрессом; объяснение проверенных шаблонов. Планирование работает и при отключённом ИИ.
- **Понятный StageOS Server.** Живой статус, HTTP-проверка, журнал, сетевые обращения, проверка профиля сети и брандмауэра. Настройка Windows сохраняет вход в аккаунт.

## Установка и обновление

Скачайте **StageOS-Release-1.0.5.zip**, снимите блокировку ZIP в свойствах Windows при наличии и полностью распакуйте. На главном ПК запустите **StageOS Server.exe**, на остальных — **StageOS.exe**. Для одного компьютера используйте **StageOS.exe**.

Перед обновлением экспортируйте резервную копию базы. Распаковывайте в новую папку; ваши пространства и аккаунты остаются в `%LOCALAPPDATA%\StageOS-Work`. Все компьютеры общей базы обновите до одной версии. В рабочем архиве нет демонстрационных сотрудников, постановок и оборудования.

## Проверки и границы релиза

Публикация выполняется после backend-тестов, браузерных сценариев, Windows Portable-сборки, запуска настоящего окна WebView2 и StageOS Server.exe. Фактические результаты, коммит, ссылка на CI и контрольные суммы включены в архив и файлы релиза.

Ручная проверка Windows 10/11 не выполнена; CI использует Windows Server 2022 x64. EXE не подписан. Для окна требуется WebView2 Runtime. Ollama и веса модели загружаются отдельно. История учится повторяющимся решениям; нейросетевые веса не дообучаются. Реальная генерация нейросетью не проверена — проверены интеграционный протокол и отказоустойчивость. Настройка сети Windows требует подтверждения системного запроса администратора; доступ другого ПК проверяется его реальным подключением.
