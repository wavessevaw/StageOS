# StageOS 1.0.1 — исправлено создание нового события

При переходе в «Назначить» форма теперь сбрасывает идентификатор и версию ранее редактируемого события, замены, ручные времена, принудительное назначение и примечания. Новый спектакль создаётся отдельно: завершённое, отменённое или идущее событие сохраняет свою историю. Кнопка «Изменить» в предварительном плане продолжает редактировать именно выбранное событие.

Скачайте StageOS-Release-1.0.1.zip, распакуйте полностью и запустите StageOS/Windows-Portable/StageOS.exe. Перед обновлением сохраните резервную копию базы в настройках. Рабочая база в %LOCALAPPDATA%\StageOS-Work сохраняется; поставка содержит пустую базу.

Принудительное назначение требует причины не менее 12 символов. Оно сохраняет конфликты и историю ручного решения, но не превращает завершённое событие в новое.

Результаты проверок приложены в TEST_RESULTS.md и BUILD_RESULTS.md. Windows Server 2022 CI; ручная приёмка Windows 10/11 не выполнена. Требуется WebView2; EXE не подписан.

## English

Creating a new event now clears the identity and edit-specific settings of a previously opened event. Completed, cancelled and running events retain their history. Explicit preview editing retains the selected event identity. Back up your database before updating, extract the entire ZIP and launch StageOS.exe. The existing working database is preserved. Exact CI receipts are included; manual Windows 10/11 acceptance remains untested.
