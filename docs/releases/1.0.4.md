# StageOS 1.0.4 — один театр, одна актуальная база

## StageOS Server

Ваш ПК становится сервером театра. Сотрудники подключаются с других компьютеров по адресу и коду, входят под своими логинами и работают с общим репертуаром, ресурсами и расписанием.

- **StageOS Server.exe** — запуск сервера и работа администратора на главном ПК.
- **StageOS.exe** — локальная работа или подключение к серверу.
- Персональные сеансы и роли: администратор, планировщик, наблюдатель.
- Автоматическое обновление данных примерно каждые 5 секунд.
- Повторная проверка назначения на сервере и защита от подтверждения устаревшего плана.
- Потеря связи не создаёт отдельно редактируемую копию базы.
- Кнопка настройки брандмауэра для частной локальной сети.
- Пошаговая инструкция развёртывания входит в архив.
- Существующие локальные данные сохраняются; данные клиента не переносятся на сервер автоматически.

**[Пошаговая инструкция настройки](https://github.com/wavessevaw/StageOS/blob/main/docs/SERVER_SETUP_RU.md)**

Скачайте `StageOS-Release-1.0.4.zip`, распакуйте полностью. Перед обновлением сделайте резервную копию. Не запускайте два экземпляра на одном серверном ПК.

Режим рассчитан на доверенную локальную сеть. Для внешнего доступа необходим VPN или настроенный HTTPS. Сервер работает, пока приложение открыто и ПК не спит; это приложение, не служба Windows. Ручная проверка на Windows 10/11 не выполнена; результаты CI — в TEST_RESULTS.md и BUILD_RESULTS.md. EXE не подписан.

# StageOS 1.0.4 — one theatre, one shared database

Turn your PC into **StageOS Server**. Staff connect with the host address and connection code, sign in with personal accounts and work with the same productions, resources and schedule.

- Host and desktop client launchers in one Portable package.
- Administrator, planner and viewer roles enforced by the host.
- Automatic data refresh approximately every five seconds.
- Server-side revalidation and stale-plan protection for concurrent changes.
- Connection loss never creates an independently edited database copy.
- Private-network Windows firewall setup button.
- Existing local data preserved; client data not merged into the host automatically.

Designed for a trusted LAN. Internet access requires a VPN or an HTTPS reverse proxy. The host must stay awake with StageOS open. Manual Windows 10/11 testing has not been performed; see CI test/build reports. Executables are unsigned.
