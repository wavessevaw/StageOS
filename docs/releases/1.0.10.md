# StageOS 1.0.10 — индикатор базы и активные пользователи сервера

Исправлена постоянная подпись «Локальная база данных» в нижнем углу приложения. Она теперь показывает фактический режим подключения:

- Клиент, подключённый к StageOS Server: **«База на сервере»**.
- ПК с запущенным сервером: **«Общая база · этот сервер»**.
- Локальный режим: **«Локальная база данных»**.

Во время определения режима показывается проверка подключения; если недоступно локальное ядро приложения, показывается соответствующая ошибка вместо предположения о локальной базе. Подпись обозначает местоположение базы; при недоступности удалённого сервера ошибки операций сохраняются как прежде, локального сохранения вместо серверного нет.

Исправлен номер версии в нижнем углу. Подписи доступны на русском и английском. Хранение и передача данных работают как в 1.0.9.

Скачайте архив, закройте приложение и распакуйте обновление отдельно. Рекомендуется обновить сервер и клиентов одновременно; сохраните резервную копию базы перед обновлением. Полная проверка backend, интерфейса и Windows-сборки выполняется до публикации; результаты приложены к архиву.

В панели сервера рядом с журналом добавлена статистика активных сетевых пользователей выбранного театра: имя, логин, роль, количество сеансов и время последнего обращения. Список обновляется вместе со статусом сервера. Доступен только администратору на серверном ПК. Одновременные сеансы одного пользователя объединяются; выход из аккаунта и истечение сеанса исключают его из списка. Закрытый клиент исчезает через 90 секунд без обращений. Серверный ПК и проверки туннеля не учитываются как удалённые пользователи. Это статистика недавней активности HTTP-сеансов, а не постоянных соединений. Данные других театров не показываются.

## English

The server panel now shows recent remote activity for the selected theatre: name, login, role, session count and last request time. Only a local administrator can see it. Sessions are grouped by account and excluded on logout, expiry or 90 seconds of inactivity. Host-local activity and tunnel probes are excluded; other theatres are not exposed.

The sidebar footer now reflects the connection mode: “Database on server” for clients, “Shared database · this server” for the host, and “Local database” for local operation. Unknown or unavailable gateway status no longer defaults to a local-database label. The footer version has also been corrected. Storage and network behavior remain unchanged from 1.0.9.
