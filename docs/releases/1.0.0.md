# StageOS 1.0.0 — каждый спектакль, один понятный план

Рабочая Windows-версия для собственного театра: локальная база, отдельное назначение события, интерактивный календарь и производственная цепочка. Начните с чистой базы и постепенно добавляйте ваши постановки, сотрудников, площадки и имущество.

## Что изменилось

- Постановка сохраняется с неполным наполнением. Площадку, исполнителей второго состава и оборудование можно добавлять позже. Недостающие участники выявляются при назначении события.
- Хор, балет, оркестр, грим, костюм и технические службы добавляются по одному человеку, с независимыми первым и вторым составами. Сохранённые события сохраняют свои фактические назначения.
- Числовые поля площадки можно очистить и ввести заново. Новому сотруднику необходимо явно выбрать подразделение.
- Русский и английский интерфейс; язык сохраняется в базе и восстанавливается при перезапуске приложения.
- Экспорт расписания в PDF и PNG: даты, площадки, помещения, этапы, вызовы и примечания. Длинные таблицы разбиваются на страницы; несколько PNG скачиваются архивом.
- Фильтр площадки включает её помещения. Параллельные репетиции в разных помещениях проверяются независимо.
- Дополнительные проверки данных, технической совместимости, отмены, согласования, импорта, исторических ссылок и текущего состояния сохранённых событий.
- Новая иконка встроена в интерфейс, окно и Windows EXE.

## Скачать и запустить

1. Скачайте `StageOS-Release-1.0.0.zip`. Если Windows показывает «Разблокировать» в свойствах ZIP, снимите блокировку перед распаковкой.
2. Распакуйте архив целиком. Запустите `StageOS/Windows-Portable/StageOS.exe`.
3. Создайте рабочую базу и добавьте собственные данные. Примерные спектакли, сотрудники и оборудование в рабочую сборку не включены.
4. Язык переключается в верхней панели. Экспорт находится во вкладке «Календарь».

Python и сервер запускать вручную не требуется. Для окна необходим Microsoft Edge WebView2 Runtime. База сохраняется в `%LOCALAPPDATA%\StageOS-Work`; перед обновлением сделайте резервную копию в настройках.

## Проверки и ограничения

Публикация выполняется только после успешных backend-, UI- и Windows-проверок этого коммита. Точные количества и ссылка на CI находятся в `GITHUB_RELEASE_BUILD.md`. Windows CI запускает настоящее окно WebView2, проверяет загрузку интерфейса, токен, иконку и корректное завершение приложения.

Проверено на Windows Server 2022 x64 в CI. Ручная проверка Windows 10/11 ещё не выполнена. EXE не подписан; используется Win32/pywebview, Tauri/NSIS не собраны. Реальная локальная LLM и PostgreSQL не проверены. Отдельные мероприятия без привязки к постановке и автоматический импорт расписаний из изображений пока не реализованы. Пользовательские названия и примечания не переводятся при переключении языка.

## English

**StageOS 1.0.0: every performance, one clear plan.** A local Windows workspace for productions, people, venues and equipment, with validated scheduling, an interactive calendar and production timelines.

This release adds incomplete production passports, independent department casts, editable venue numbers, persisted Russian/English language selection, and offline PDF/PNG schedule export grouped by dates, venues and rooms. Existing events retain their saved assignments. The working build starts with an empty database.

Extract the entire ZIP, unblock it first if Windows offers that option, and launch `StageOS/Windows-Portable/StageOS.exe`. Python and the server start automatically. Microsoft Edge WebView2 Runtime is required. Back up your database before updating.

Publication is gated by backend, browser UI and Windows build checks, including a real native WebView2 window. Exact results are included in `GITHUB_RELEASE_BUILD.md`. Windows Server 2022 CI is verified; manual Windows 10/11 acceptance, real local LLM and PostgreSQL tests remain outstanding. The executable is unsigned. Standalone events without a production and image-to-schedule import are not implemented.
