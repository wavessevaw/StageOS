# StageOS 1.0.15

Cloudflare Quick Tunnel добавлен в StageOS Server как бесплатный способ внешнего подключения. Аккаунт, домен и ключ не нужны. Сервер скачивает официальный cloudflared 2026.10.0 для Windows x64 и сверяет SHA-256. База и учётные записи остаются на вашем ПК.

## Как включить

1. Обновите сервер и клиент до 1.0.15. Запустите StageOS Server и войдите администратором.
2. Откройте окно сервера → «Доступ через Интернет» → «Сервис туннеля: Cloudflare Quick Tunnel».
3. Нажмите «Установить Cloudflare», затем «Запустить интернет-туннель».
4. Дождитесь проверенного внешнего адреса и нажмите «Скопировать адрес».
5. На телефоне откройте ссылку в Safari и войдите своим логином и паролем. Для полного интерфейса на ПК также потребуется код подключения сервера.

Проверка адреса сначала сверяет уникальный идентификатор вашего сервера и только потом передаёт код подключения. Управлять туннелем могут только администраторы на компьютере сервера; удалённым клиентам управление закрыто. При остановке сервера останавливается и принадлежащий ему агент.

## Адрес и соединение

Ссылка остаётся одной в течение текущего запуска туннеля. Краткий обрыв связи и внутреннее переподключение агента не создают новый адрес. После остановки или нового запуска Quick Tunnel ссылка меняется. Сервер и компьютер должны оставаться включёнными. Постоянного адреса и гарантии непрерывной доступности у бесплатного режима нет.

По умолчанию используется HTTP/2 через TCP. Если подключение не устанавливается, можно остановить туннель и выбрать автоматический режим или QUIC. Статус показывает проверенный ответ StageOS, а не только факт запуска агента. При сбоях проверки повторяются с увеличением интервала, без частого опроса внешнего адреса. Ошибки DNS показаны отдельно; произвольный вывод агента в журнал не попадает.

ngrok сохранён как альтернативный сервис. Сохранённая настройка ngrok не теряется; для перехода выберите Cloudflare после остановки старого туннеля.

## Быстрее на телефоне

Личное расписание загружается отдельно от редактора постановок и полного календаря. Контрольная production-сборка: около 103 КБ сжатого JavaScript для мобильного входа вместо 225 КБ общего файла. Это размер файлов, а не гарантия времени загрузки. Для HTML включена повторная проверка кеша; после обновления сервера браузер получает актуальные имена файлов. Ошибка загрузки раздела показывает кнопку повторной загрузки вместо пустого экрана.

Сохраняются сжатие API, ограничение параллельного опроса, пауза фоновых вкладок и восстановление сеанса. Операции записи автоматически не повторяются.

Общий вызов артистов перенесён с главной формы внутрь «Проверить и назначить». Выбор сразу пересчитывает назначения и конфликты. Исправлен возврат из редактора постановки в репертуар, уточнены подписи базы театра.

## Проверки и ограничения

Сборка публикуется только после обязательных серверных, сетевых, браузерных и Windows-проверок. Cloudflare проверяется контролируемыми ответами и процессами; официальный Windows-агент скачан, контрольная сумма и запуск проверены. Реальная попытка подключения в среде разработки остановилась на поиске SRV-записей Cloudflare через DNS. Поэтому внешний доступ в вашей сети пока не подтверждён. Проверка сервера не доказывает доступность из сети пользователя: после настройки проверьте ссылку с телефона через мобильный интернет без VPN. Cloudflare также может ограничиваться провайдером; программа не гарантирует обход сетевых ограничений.
