# StageOS 1.0.4 — панель сервера и настройка Windows

Панель «Подключение к серверу» показывает статус каждые 2 секунды, порт, ответ HTTP,
проверенное правило брандмауэра, тип сетей Windows и время последней проверки.
Внизу — журнал с временем действий, ошибок и подключений. В основном интерфейсе
остаётся индикатор сервера: нажмите на него, чтобы открыть панель.

## Настройка
1. Запустите StageOS Server.exe и войдите администратором своего театра.
2. Нажмите индикатор сервера или Личный аккаунт → Подключение к серверу.
3. Дождитесь проверки. Если сервер остановлен, нажмите «Запустить сервер».
4. Выберите свою доверенную локальную сеть (например, Ethernet театра).
5. Нажмите «Настроить Windows» и подтвердите запрос администратора Windows.
   Программа переводит только выбранную сеть из общедоступной в частную и создаёт
   правило TCP для своего встроенного Python, своего порта и локальной подсети.
   Другие сети и доменные политики не меняются. Для создания только правила
   выберите «Только правило брандмауэра».
6. Дождитесь результата: «Правило разрешает подключения» и «Частная».
7. На другом компьютере укажите показанный LAN-адрес и код. Счётчик сетевых запросов
   и время последнего запроса покажут, что клиент обратился к серверу с верным кодом.
   Этот счётчик не является числом пользователей онлайн.

«Сервер работает» подтверждает сетевой слушатель. «HTTP: отвечает» подтверждает
локальный запрос к нему. Правило проверяется в действующем хранилище Windows:
программа, порт, протокол, профиль, адреса и разрешение. Ни одна локальная проверка
не гарантирует прохождение роутера или стороннего антивируса: это проверяется
подключением второго компьютера. Отключение всего брандмауэра не выполняется.

## Установка обновления поверх 1.0.4
Закройте оба приложения. Сохраните резервную копию папки Windows-Portable/app.
Разблокируйте ZIP в свойствах файла, если Windows показывает этот пункт.
Распакуйте содержимое обновления в Windows-Portable с заменой файлов папки app.
Патч включает backend, сценарии Windows, windows_desktop.py и собранный frontend.
База, runtime и аккаунты не заменяются. Предыдущий патч входа уже включён.
Для отката закройте приложение и восстановите резервную копию app.

## Проверки
Локально: 27 тестов сети и аккаунтов прошли; Windows-тест пропущен на Linux.
4 браузерных теста прошли, включая реальные изменения общей базы двух клиентов,
индикатор, HTTP, журнал и повторный запуск без выхода из аккаунта.
Состояния Windows в браузерном тесте имитируются; настоящее создание и чтение
правила проверяет отдельный Windows-тест в GitHub Actions.
TypeScript и сборка frontend прошли. Интерактивный запрос UAC на ПК пользователя
и физическое подключение двух ПК не проверены в этой среде.
