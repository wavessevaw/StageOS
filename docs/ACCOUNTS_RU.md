# Театры и личные аккаунты

При запуске StageOS 1.0.3 сначала откройте своё пространство театра, затем войдите по логину и паролю. Новому театру создаётся пустая база. Существующая рабочая база обнаруживается по прежнему пути; её содержимое сохраняется. При первом переходе со старой версии настройте первого администратора, если персональная настройка входа ещё не установлена.

У каждого театра отдельные базы, пользователи, ресурсы, предложения и настройки. Одинаковый логин можно использовать в разных театрах; права в одном театре не дают доступ к другому. Переключение театра завершает личный сеанс, после чего нужно войти в выбранный театр. Перезапуск сервера также завершает сеансы.

| Роль | Права |
|---|---|
| Администратор | Все функции своего театра, пользователи и роли, импорт/экспорт базы, согласование и принудительное назначение |
| Планировщик | Расписание, постановки, площадки, сотрудники и имущество; без управления аккаунтами, импорта базы, согласования и обхода конфликтов |
| Наблюдатель | Просмотр данных, аналитики и календаря, проверка предварительного варианта; без изменения производственных данных |

Откройте своё имя в правом верхнем углу. Здесь доступны «Выйти из аккаунта», «Переключить театр» и «Изменить пароль». У администратора также есть «Пользователи и роли»: создание аккаунта, изменение роли, отключение и сброс пароля. Последнего действующего администратора нельзя отключить или понизить. Сброс пароля и изменение прав закрывают сеансы изменённого пользователя.

Пароли хранятся с индивидуальной солью и PBKDF2-SHA256 (600 000 итераций). Сеанс ограничен 12 часами; cookie HttpOnly/SameSite=Strict, повторные неудачные входы ограничены. Это локальная авторизация приложения: она не шифрует SQLite и не защищает файлы от владельца Windows или администратора компьютера. Сервер слушает только 127.0.0.1; доступ из интернета этой версией не предоставляется.

## Резервирование

Обычный экспорт .db сохраняет данные выбранного театра и не переносит его учётные записи. Импорт внутри театра меняет только его производственную базу; права остаются прежними. Для полной резервной копии закройте StageOS и сохраните весь каталог `%LOCALAPPDATA%\StageOS-Work`, включая `accounts.sqlite`, файл выбора прежней базы и каталог `theatres`. Если ранее открывали базу вне этого каталога, сохраните её тоже.

## Персональная настройка первоначальных администраторов

У публичной версии нет общего заранее заданного пароля. Отдельный доверенный файл `bootstrap-accounts.json` содержит три начальных администратора с хешами паролей. При необходимости положите его рядом с StageOS.exe **до первого запуска версии с аккаунтами** либо в каталог данных. Он применяется только к уже существующим пространствам без пользователей и никогда не заменяет настроенные аккаунты. После успешного входа файл можно убрать. Не публикуйте и не пересылайте чужим людям файл с настройкой ваших администраторов.
