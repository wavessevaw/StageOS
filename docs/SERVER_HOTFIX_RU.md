# StageOS 1.0.4 — исправление запуска сервера

Проблема: сохранение настроек сервера удаляло cookie вошедшего администратора.
Следующие запуск сервера или настройка брандмауэра требовали войти повторно.

Исправлено:
- Вход сохраняется при локальном режиме, запуске/остановке и настройке сервера.
- Повторный запуск с тем же портом не отключает работающих клиентов.
- При переходе к другому серверу сессия по-прежнему сбрасывается.
- Настройка Windows ожидает завершения повышенного PowerShell и проверяет результат.
  Ошибка, отмена повышения прав и таймаут не выдаются за успех.
- Сценарий настройки брандмауэра проверяет созданное правило; при ошибке пишет
  Windows-Portable/app/backend/firewall-error.log (если есть право записи).

Установка поверх 1.0.4:
1. Закройте StageOS.exe и StageOS Server.exe.
2. Сохраните резервные копии app/backend/network.py и app/backend/firewall.ps1.
3. В свойствах скачанного ZIP нажмите «Разблокировать», если этот пункт есть.
4. Распакуйте содержимое ZIP в Windows-Portable, рядом с StageOS Server.exe.
   Согласитесь заменить ДВА файла в app/backend.
   Правильный итоговый путь: Windows-Portable/app/backend/network.py.
5. Запустите StageOS Server.exe. Войдите в свой театр администратором.
6. Личный аккаунт → Подключение к серверу. Нажмите «Запустить сервер», если нужно,
   затем «Разрешить подключения в Windows». Подтвердите запрос Windows и дождитесь результата.
7. Если написано «Сервер работает», повторно запускать его не требуется.

База, аккаунты и код подключения патчем не заменяются. Номер приложения остаётся 1.0.4.
Для отката закройте программу и восстановите две резервные копии.

Проверки: 24 теста сети и аккаунтов успешно (Linux, Python 3.12).
В том числе реальный HTTP между сервером и двумя клиентами, сохранение входа,
повторный запуск без разрыва соединений, сброс сессии при смене источника базы.
Тесты результата PowerShell выполнялись с подменой процесса: успех, ошибка,
отмена/ненулевой код, таймаут, отсутствие PowerShell.
Ручная проверка UAC и брандмауэра на Windows для этого патча не выполнена.
