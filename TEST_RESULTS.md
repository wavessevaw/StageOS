Новые регрессионные проверки: первый запуск без примеров; создание постановки с пустого шаблона; отклонение ошибочных паспортов; неизменность сохранённого состава после изменения постановки; закрытие площадки и глубина декорации; защита отменённых событий и фактических работ; удаление несвязанного ресурса при совпадающем числовом параметре; неправильные интервалы/тип количества; вместимость комнаты и закрытие здания; вызов технического участника к подготовке репетиции; утренний выезд без сдвига обеда и вечернего демонтажа.

Регрессия интерфейса проверяет создание, предварительный план, подтверждение, календарь, режимы день/неделя/месяц/производство, фильтры, реальные drag/resize, замены, создание/редактирование постановки, имущество поштучно, площадки, выборочную репетицию, примечания, предложения/отклонение, принудительное сохранение конфликтов и отключённый ИИ.

Один warning относится к deprecated интерфейсу FastAPI/Starlette TestClient с httpx; он не означает ошибку рабочего приложения. Vite предупреждает о размере JS bundle; сборка успешна.

Демо-фикстуры используются только в тестах регрессии. Отдельный рабочий UI-сценарий выполняется с отключёнными demo endpoints и изначально нулевыми ресурсами/постановками/событиями.

Windows GUI, реальная локальная LLM и PostgreSQL локально не проверены. GitHub Actions добавлен для независимой повторной проверки и Windows runtime; его результат не включён в эти локальные числа.
